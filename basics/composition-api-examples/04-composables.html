Composition API: Composables

Composables are reusable functions that encapsulate stateful logic

Example 1: useCounter Composable

Counter A: {{ counterA.count }}

Counter B: {{ counterB.count }}

Each counter has its own independent state!

Example 2: useMouse Composable

Move your mouse around to see coordinates

X: {{ mouse.x }}
Y: {{ mouse.y }}

Example 3: useOnlineStatus Composable

Network Status: {{ isOnline ? 'Online' : 'Offline' }}

Try turning your network on/off to see the status change

Example 4: useLocalStorage Composable

Stored value: {{ storedName }}

Your name is saved to localStorage and persists across page refreshes!
